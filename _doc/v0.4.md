## 新增功能

### 1. Lock Manager API
```rust
pub struct LockManager;

impl LockManager {
    pub fn read_lock(&self, page_id: u64) -> LockGuard;
    pub fn write_lock(&self, page_id: u64) -> LockGuard;
}
```

- **read_lock()**: 讀取鎖 - 允許多個 reader 同時讀取
- **write_lock()**: 寫入鎖 - 獨占，排除 reader 和其他 writer

### 2. PageLatch 結構
```rust
pub struct PageLatch(());
```
- 頁面級鎖的基礎單位
- 預設為 placeholder，未來可擴展為實際 RwLock

### 3. LockGuard
- RAII 風格的鎖守護者
- Drop 時自動釋放鎖
