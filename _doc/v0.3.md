# btree6 v0.3 版本記錄

## 更新日期
2026-05-15

## 版本資訊
- **版本**: 0.3.0
- **狀態**: 檔案持久化完成

## 新增功能

### 1. 檔案持久化完整支援
- **BTreeHeader**: 檔頭結構，儲存於 page 0
  - magic number: 檔案識別
  - root_page: 根頁面編號
  - page_count: 總頁數
  - size: key-value 數量

- **自動恢復**: 重新開啟檔案時自動讀取 header 恢復 tree 狀態

- **flush()**: 每次 flush 時自動更新 header 並寫入磁碟

### 2. 檔案布局
```
Page 0: BTreeHeader (metadata)
Page 1+: 實際 B+Tree 節點資料
```

### 3. Storage trait 擴展
- `set_header()`: 設定 header 並寫入磁碟
- `header()`: 取得目前 header

## API 使用範例

```rust
use btree6::{BPlusTree, Key};

// 建立檔案 tree
let mut tree = BPlusTree::open("data/myindex.bt", 4).unwrap();

// 插入資料
tree.insert(Key::Integer(1), b"hello".to_vec());
tree.insert(Key::Integer(2), b"world".to_vec());

// 寫入磁碟
tree.flush();

// 重新開啟 - 自動恢復
let mut tree2 = BPlusTree::open("data/myindex.bt", 4).unwrap();
assert_eq!(tree2.len(), 2);
assert_eq!(tree2.get(&Key::Integer(1)), Some(b"hello".to_vec()));
```
