## 新增功能

### 1. 完整 CRUD 操作
- **Insert**: 插入 key-value，可自動 split
- **Get**: 單一 key 查詢
- **Range**: 範圍查詢 [start, end]
- **Update**: 相同 key 覆寫舊值
- **Delete**: 刪除指定 key

### 2. 儲存後端
- **MemoryStorage**: 記憶體儲存（測試用）
- **FileStorage**: 單一檔案儲存（磁碟持久化）

### 3. Page 結構
- PageHeader: 包含 magic number, page_id, checksum
- ItemId: 行指針
- CRC32 校驗和驗證

### 4. Lock 機制
- LockManager: 頁面級鎖管理（目前為 placeholder）

## API 使用範例

```rust
use btree6::{BPlusTree, Key};

// 建立記憶體 tree
let mut tree = BPlusTree::memory(4);

// 插入
tree.insert(Key::Integer(42), b"hello".to_vec());

// 查詢
assert_eq!(tree.get(&Key::Integer(42)), Some(b"hello".to_vec()));

// 範圍查詢
let results = tree.range(&Key::Integer(1), &Key::Integer(10));

// 更新
tree.insert(Key::Integer(42), b"world".to_vec());

// 刪除
tree.delete(&Key::Integer(42));
```
