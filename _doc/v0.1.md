# btree6 規劃文件 v0.1

## 專案概述

獨立的 Rust B+Tree 實現，參考 PostgreSQL 風格：
- 單一資料夾儲存多個 index 檔案
- 頁面級細緻 lock
- MVCC 支援（可選）
- 高效能、高併發、安全穩定

## 目標場景

1. 教學用途：理解 B+Tree 實作細節
2. 嵌入專案：作為 sql6 的模組化版本
3. 高效能儲存引擎：替換現有 btree 實作

### 2. Page 設計

```rust
// Page 結構 (PostgreSQL 風格，8KB)
struct Page {
    header: PageHeader,      // 頁頭：LSN, checksum, type
    free_space: u16,         // 剩餘空間
    special: u16,            // 特殊區域偏移
    items: [ItemId; N],     // 行指針陣列
    data: [u8],             // 實際資料
}
```

- **Page 大小**: 8KB（可設定）
- **ItemId**: `(offset, length)` 行指針
- **LSN**: Write-Ahead Logging 標記

### 3. 節點結構

```
┌─────────────────────────────────────┐
│ Internal Node                       │
├─────────────────────────────────────┤
│ keys: [key1, key2, key3, ...]      │
│ children: [ptr0, ptr1, ptr2, ...]  │
└─────────────────────────────────────┘

┌─────────────────────────────────────┐
│ Leaf Node                           │
├─────────────────────────────────────┤
│ keys: [key1, key2, ...]            │
│ values: [val1, val2, ...]          │
│ next_leaf: Option<page_id>         │
│ prev_leaf: Option<page_id>         │
└─────────────────────────────────────┘
```

### 4. Lock 策略

#### 4.1 兩層 Lock 機制

```
┌──────────────────────────────────────┐
│          Lock Manager                │
├──────────────────────────────────────┤
│  PageLockManager: HashMap<page_id, │
│      RwLock<PageLatch>>             │
└──────────────────────────────────────┘
```

#### 4.2 Lock 類型

| Lock | 用途 | 特性 |
|------|------|------|
| `ReadLatch` | 讀取 page | 多 reader 可共存 |
| `WriteLatch` | 寫入 page | 獨占，阻塞 writer |
| `TreeLatch` | 修改結構（分裂/合併）| 整棵樹維度 |

#### 4.3 Deadlock 避免

1. **Lock Ordering**: 總是先 lock 小 page_id
2. **Try-Lock**: 使用 `try_read()` / `try_write()`
3. **Timeout**: 超時自動 abort
4. **Deadlock Detection**: 圖論 cycle 檢測（可選）

### 5. 交易支援（可選）

```rust
trait Transactional {
    fn begin(&mut self) -> TransactionId;
    fn commit(&mut self, xid: TransactionId);
    fn abort(&mut self, xid: TransactionId);
}
```

- **MVCC**: 每個 tuple 有 `xmin`, `xmax`
- ** Vacuum**: 清理dead tuple

## API 設計

```rust
use btree6::{BPlusTree, Key, Value};

// 建立 tree
let mut tree = BPlusTree::open("data/myindex.bt", 4)?;

// 插入
tree.insert(Key::Integer(42), b"hello".to_vec())?;

// 查詢
let result = tree.get(&Key::Integer(42));

// 範圍查詢
let results = tree.range(&Key::Integer(1), &Key::Integer(100))?;

// 刪除
tree.delete(&Key::Integer(42))?;

// 游標走訪
let mut cursor = tree.cursor();
for entry in cursor {
    println!("{:?}", entry);
}
```

## 效能優化

1. **LRU Cache**: 熱門 page 快取
2. **Bulk Load**: 大量資料快速建索引
3. **Prefetch**: 順序讀取時預讀
4. **Bloom Filter**: 快速判斷 key 不存在

## 安全穩定

1. **Checksum**: 每頁校验和
2. **WAL**: 預寫日誌 recover
3. **fsck**: 一致性檢查工具
